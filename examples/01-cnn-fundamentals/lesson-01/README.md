# Lesson 1: Pixel values example

## Prerequisites

Python 3.11 or later and the course environment created with `uv sync`. The script uses only the Python standard library.

## Run

From the repository root:

```bash
uv run python examples/01-cnn-fundamentals/lesson-01/image_pixels.py
```

## Expected output

```text
Image size: 5 x 5
Pixel values: 25
Bright pixels: 7
```

## Limitations

This is a tiny hand-written grid, not an MNIST loader or a neural network. It illustrates that an image is represented by pixel numbers.
