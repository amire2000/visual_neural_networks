# Visual Neural Networks

Learn how neural networks make sense of images, from the first pixel to real-time computer vision. This beginner-friendly course uses visual and intuitive explanations, minimal mathematics, and practical examples centered on MNIST, CIFAR-10, and PyTorch.

## Course at a glance

- **15 lessons** across four progressive stages.
- Start with grayscale MNIST digits and build a mental model of CNNs.
- Move to color images, deeper CNNs, ResNet, and transfer learning.
- Explore Vision Transformers, self-supervised learning, and object detection.
- Finish with inference optimization and real-time deployment concepts.

## Learning approach

Each lesson makes ideas visible and understandable before introducing technical detail. Start with [0 - Setup Lab](lesson-00-setup-lab/index.md) to create the course environment and download MNIST. Then [1 - How Neural Networks See Images](modules/01-cnn-fundamentals/lesson-01-how-neural-networks-see-images/index.md) explains how an image becomes numerical input and how a CNN turns it into a prediction. Lesson 0 is course setup and is not counted in the 15-lesson syllabus.

Start with the [roadmap](roadmap.md) for the learning path or open the complete [syllabus](syllabus.md).
