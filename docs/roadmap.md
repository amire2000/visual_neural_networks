# Roadmap

## Final goal

Build an intuitive understanding of how modern vision models learn from images and what it takes to run them efficiently in real systems.

| Stage | Lessons | Module | Dataset / focus | Milestone |
| --- | --- | --- | --- | --- |
| 1 | 1–6 | CNN Fundamentals | MNIST | Understand, train, and evaluate a basic MNIST CNN. |
| 2 | 7–10 | Understanding Modern CNNs | CIFAR-10 | Understand foundational modern CNN techniques and pretrained-model adaptation. |
| 3 | 11–13 | Modern Computer Vision | ViT, self-supervision, detection | Understand the conceptual differences among CNNs, Vision Transformers, self-supervised learning, and object detection. |
| 4 | 14–15 | Practical Computer Vision | Optimization and deployment | Understand the fundamentals of optimizing and deploying vision models for real-time inference. |

## Recommended sequence

Before Stage 1, complete [Lesson 0: Setup Lab](lesson-00-setup-lab/index.md) to prepare the Python environment and download MNIST. Then work through the stages in order. The first stage builds the image and CNN mental model; later stages extend it to richer images, newer model families, and practical inference constraints.

See the [syllabus](syllabus.md) for each lesson's concepts and intended outcome.
